whoscored-event-data

A polite, typed Python SDK for scraping football match event data from Whoscored's chalkboard — a full rewrite of the original Selenium + notebook project.

v2.0.0 No browser needed for data Rate-limited Cached Proxy-aware Offline-tested Python ≥ 3.9

Overview

What changed versus the original project:

  • Typed, documented API — no more copy-pasting notebook cells.
  • Fast & polite — match-centre pages are fetched over plain HTTP with built-in rate limiting (default 7 s + random jitter) and caching, instead of driving a full browser per match.
  • Auto browser fallback — Whoscored intermittently challenges even match pages with a bot wall. When the HTTP backend hits one (HTTP 403), the client transparently re-fetches through a real browser.
  • Robust parsing — the event feed is decoded as real JSON rather than brittle string-splitting.
  • Backwards compatible — the old main.py function names still exist as shims.

Installation

# from the repo
pip install -r requirements.txt        # or: pip install -e .

# as a package
pip install whoscored-event-data

Core dependencies: pandas, numpy, requests, beautifulsoup4, lxml, tqdm. selenium is only needed for the Cloudflare-protected listing pages. Visualisation extras (matplotlib, seaborn, mplsoccer) live in requirements-visuals.txt.

Quick start

from whoscored import WhoscoredClient

with WhoscoredClient() as client:      # polite by default
    match = client.get_match(1650630)   # id or full match URL

print(f"{match.home.name} {match.score} {match.away.name}")
# -> Barcelona 0 : 0 Rayo Vallecano

events = match.events                  # pandas DataFrame, one row per event
events_with_epv = match.add_epv()      # appends an EPV column
match.matches_df                       # match-level summary frame

events.to_csv("events.csv", index=False)

The events DataFrame carries 258 columns per event — type, outcome, player, team, minute, period, pitch coordinates, associated player/event ids, and more — and is row-identical to the legacy scrape for the same matches.

League & fixture discovery

League and fixture listing pages are Cloudflare-protected and require a real browser. A snapshot of every league is bundled with the package, so listing leagues needs no network:

client.list_leagues()          # -> {"spain-laliga": "https://www.whoscored.com/...", ...}

To re-scrape the live list or list a season's fixtures:

with WhoscoredClient(backend="browser") as client:   # Firefox, headed
    fixtures = client.list_fixtures("spain-laliga", "2022/2023")
    lfc = client.team_fixtures("Barcelona", fixtures)
NoteWhoscored ships generated CSS class names, so the discovery selectors may occasionally need updating when Whoscored changes its front-end. The match-centre pipeline (the part that gives you data) is unaffected because it never touches those pages.

Proxies

Spread requests over multiple IPs with a static proxy or a rotating pool:

from whoscored import WhoscoredClient, ProxyRotator

# Static proxy
with WhoscoredClient(proxy="host:port") as client:
    client.get_match(1650630)

# Rotating pool (validated against a neutral endpoint)
pool = ProxyRotator(proxies=["p1:8080", "p2:3128"], validate=True)
with WhoscoredClient(proxy_pool=pool) as client:
    client.get_matches([1650630, 1650634])

# Free lists from public sources
with WhoscoredClient(free_proxies=True) as client:
    client.get_matches(urls)

When a pool is configured, blocked or dead proxies are skipped automatically — the transport rotates to the next one and only fails once every proxy has been tried. Proxies are validated against gstatic.com, never against Whoscored.

Honest warningFree proxy lists are dominated by datacenter IPs that Whoscored's bot protection blocks outright (all returned HTTP 403 in testing). A pool is most useful with residential proxy services (paid) or your own proxy servers. Treat free proxies as untrusted middlemen.

Politeness & avoiding bans

This SDK is designed to keep your IP safe:

  • Rate limiting — at least 7 seconds (plus jitter) between requests by default. Tune with request_delay=/jitter= or the CLI --delay flag.
  • Caching — pass cache_dir=".whoscored_cache" so re-runs never touch the site.
  • One request per match — the whole event feed is embedded in a single page; no per-match crawl.
  • Realistic headers — browser user-agent and referer are sent by default.
  • Auto fallback — a challenged page is retried through a real headed browser rather than hammering the HTTP endpoint.
  • No headless browsers for Cloudflare pages (headed Firefox is far less likely to be flagged).
Heads-upWhoscored's bot protection is intermittent and can trigger after a burst of requests. The SDK surfaces these as BlockedError with a clear message. Stop scraping for a while if you keep seeing them — continuing only prolongs the block. Respect Whoscored's terms of service and keep delays generous.

Browser troubleshooting

  • Ubuntu/Debian snap Firefox: /usr/bin/firefox is a shell wrapper, not a real binary, so geckodriver fails with binary is not a Firefox executable. The SDK auto-detects the real binary at /snap/firefox/current/usr/lib/firefox/firefox (override via WhoscoredClient(binary_location="...") or FIREFOX_BIN).
  • Driver shutdown noise is handled automatically: the benign Error terminating service process/PermissionError tracebacks from snap-packaged geckodriver and Selenium Manager's cosmetic might not be compatible warning are silenced. Set SE_DEBUG=1 or WHOSCORED_DEBUG=1 to restore diagnostics.
  • Missing geckodriver/chromedriver: the browser backend auto-locates the driver via PATH (or SE_GECKODRIVER/SE_CHROMEDRIVER).

Worked examples

Fetch many matches and save them

from whoscored import WhoscoredClient, save_dataframe

urls = [
    "https://www.whoscored.com/Matches/1650630/Live/Spain-LaLiga-2022-2023-Barcelona-Rayo-Vallecano",
    "https://www.whoscored.com/Matches/1650634/Live/Spain-LaLiga-2022-2023-Osasuna-Sevilla",
]
with WhoscoredClient(cache_dir=".whoscored_cache") as client:
    matches = client.get_matches(urls)

for match in matches:
    save_dataframe(match.add_epv(), f"data/events_{match.match_id}.csv")

A whole season for one team

with WhoscoredClient(backend="browser") as client:
    fixtures = client.list_fixtures("spain-laliga", "2022/2023")
    barca = client.team_fixtures("Barcelona", fixtures)

# Take the match ids/urls and fetch them over the fast HTTP backend
with WhoscoredClient() as client:
    matches = client.get_matches([f.url for f in barca])

Testing

The test suite runs entirely offline against a real captured match page, so it never risks getting your IP flagged:

python test.py           # offline suite (47 tests)
python test.py --live    # also fetches one real match (single polite request)

Backwards compatibility

The original notebook API still works via main.py shims (with a DeprecationWarning):

import main
leagues = main.getLeagueUrls("spain-laliga")
fixtures = main.getMatchUrls("spain-laliga", "2022/2023")
events = main.createEventsDF(data)
epv = main.addEpvToDataFrame(events)
grid = main.load_EPV_grid()

Available shims: getLeagueUrls, getMatchUrls, getTeamUrls, getMatchesData, getMatchData, getFixtureData, createEventsDF, createMatchesDF, translateDate, getSortedData, load_EPV_grid, get_EPV_at_location, to_metric_coordinates_from_whoscored, addEpvToDataFrame, main_url, TRANSLATE_DICT.
